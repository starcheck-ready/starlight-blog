# 巫師 3 重製版｜Steam Deck 設定：跳過啟動器、XeSS 品質、60 FPS 取捨清單

> 適用版本：巫師 3 重製版（繁中），Steam Deck 掌機模式。
> 解析度基準：1280×800（Deck 原生）。
> 設定來源：實機逐項抄錄（2026-11-27）。

**一句話結論**：這組設定的邏輯是「關掉所有會晃眼、會吃效能的效果，把預算集中在 XeSS 品質與材質」，用 60 FPS 上限換穩定幀數，而不是追求全部拉滿。

## 0. 30 秒版

- **啟動選項**加 `--launcher-skip`，開遊戲直接進主選單
- **顯示**：無邊框視窗、垂直同步開、1280×800、上限 60 FPS、硬體游標關
- **影像**：光追關、反鋸齒選 XeSS（品質）、畫格生成與所有低延遲選項全關、毛髮關
- **三條取捨原則**：
  1. 材質是唯一拉到「高」的項目（幾乎不吃運算、只吃記憶體）
  2. 陰影、水、樹葉、草叢、背景角色一律「中」——這些是幀數的主要支出
  3. 動態模糊、模糊、銳利度全關；景深、色差、暈影、光束等電影感效果留著
- **掉幀時**：先降陰影 → 樹葉可見距離 → 草叢密度，最後才動 XeSS 品質（見 §5）

## 1. 啟動選項：跳過啟動器

Steam 收藏庫 → 對遊戲按齒輪 → **內容 → 一般 → 啟動選項**，填入：

```
--launcher-skip
```

- 作用：略過啟動器，直接進入遊戲本體，少一層點擊。
- 不動存檔、不動畫質設定；之後想進啟動器（例如手動選 DLC）把這行刪掉即可。
- 這是唯一一項在「遊戲外」設定的東西，建議**先設完再進遊戲改畫質**，省得來回切。

## 2. 顯示設定（影像 → 顯示）

| 選項       | 設定         | 說明                                                     |
| ---------- | ------------ | -------------------------------------------------------- |
| 顯示模式   | 無邊框視窗   | 掌機上與全螢幕表現接近，切換時不會黑屏重抓訊號           |
| 垂直同步   | 開啟         | 搭配 60 上限，避免畫面撕裂                               |
| 解析度     | 1280×800     | Deck 原生解析度，不要動                                 |
| 最大 FPS   | 60           | 上限而非保證；實際幀數看場景，見 §5                     |
| 硬體游標   | 關閉         | 掌機以搖桿／觸控板操作，用不到系統游標；外接滑鼠覺得飄再開 |

> 「最大 FPS」是天花板，不代表全程 60。市區與沼澤會掉，這是 Deck 的正常表現，不是設定壞了。

## 3. 影像設定（影像 → 影像）

### 3.1 光線追蹤與升頻

| 選項                      | 設定   |
| ------------------------- | ------ |
| 光線追蹤                  | 關閉   |
| 反鋸齒                    | XeSS   |
| XeSS 品質                 | 品質   |
| AMD FSR 低延遲 2.0        | 關閉   |
| XeSS 畫格生成             | 關閉   |
| XeSS 低延遲               | 關閉   |
| NVIDIA 毛髮技術           | 關閉   |
| 銳利度                    | 關閉   |
| 螢幕空間環境光遮蔽        | GTAO   |
| GTAO 品質                 | 高     |
| 螢幕空間反射              | 低     |
| 螢幕空間陰影              | 開啟   |

為什麼這樣選：

- **光追關閉**：Deck 的 GPU 沒有餘裕同時撐光線追蹤與 60 上限，開了等於直接把幀數砍半。
- **升頻用「品質」檔**：內部渲染解析度已經不高，再往下調（平衡／效能）畫面會明顯糊；寧可少幾幀也要保住清晰度。
- **低延遲與畫格生成全關**：這三項是為高幀競技場景設計的，巫師 3 是動作 RPG，關掉換取最單純的延遲與畫面。
- **毛髮技術關閉**：HairWorks 是這款遊戲最貴的單一效果之一，關掉對幀數最直接。
- **環境光遮蔽留「高」、反射壓「低」**：GTAO 對畫面立體感的加分明顯且成本可控；螢幕空間反射在大片水面的沼澤區很吃效能，壓低最划算。
- **銳利度關閉**：交給 XeSS 自己處理，避免升頻後再銳化造成邊緣過曝。

### 3.2 鏡頭效果

| 選項     | 設定 |
| -------- | ---- |
| 動態模糊 | 關閉 |
| 模糊     | 關閉 |
| 景深     | 開啟 |
| 色差     | 開啟 |
| 暈影     | 開啟 |
| 光束     | 開啟 |
| 鏡頭效果 | 開啟 |
| 反射     | 開啟（原文如此，見 §7） |

要點：**真正會暈的是動態模糊**，所以關；其餘（景深、色差、暈影、光束、鏡頭效果）成本低，留著讓過場與法印演出有層次。這組是「實用優先，但不犧牲電影感」的分法。

### 3.3 畫質細節

| 選項             | 設定 |
| ---------------- | ---- |
| 背景角色的數量   | 中   |
| 陰影品質         | 中   |
| 水品質           | 中   |
| 樹葉可見距離     | 中   |
| 草叢密度         | 中   |
| 質地品質         | 高   |
| 細節層次         | 中   |

要點：

- **質地品質（材質）是唯一拉高的項目**：它幾乎不佔 GPU 運算，主要是吃記憶體，Deck 的共用記憶體撐得住，性價比最高。
- **陰影、樹葉、草叢、背景角色**全都壓在「中」：這四項是開放世界最常見的幀數支出，也是「中 → 高」畫質提升最有感、掉幀也最有感的地方。
- **細節層次（LOD）中**：遠景物件切換不會太突兀，又不會為了遠處的草多算一遍。

## 5. 掉幀時先動這幾個（編輯建議，非原始設定）

依「對幀數影響大、對畫面影響相對小」的順序往下調，一次只改一項，改完在同一個場景繞一圈再決定要不要繼續：

1. **陰影品質**：中 → 低
2. **樹葉可見距離**：中 → 低
3. **草叢密度**：中 → 低
4. **背景角色的數量**：中 → 低
5. 最後才降 **XeSS 品質**：品質 → 平衡

不建議動的：材質（幾乎不掉幀）、解析度（1280×800 是底線）、垂直同步（關了會撕裂）。

## 6. 適用情境與限制

- 這組設定是**掌機模式、原生 800p** 的配置；接電視或外接螢幕時解析度要另外調。
- 「最大 FPS 60」不等於全程 60：諾維格瑞市區、沼澤、陶森特鮑克蘭這類場景本來就會掉，屬正常。
- 沒有幀數顯示數據的項目（1% low、平均 FPS、續航）本文不寫死，等實測後補（見 §7）。
