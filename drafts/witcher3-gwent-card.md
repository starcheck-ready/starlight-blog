## 2. 戰術核心：間諜 ＋ 誘餌

**間諜**打出後會跑到對手場上，等於白送對手戰力，但你能**抽 2 張牌**。用「這一局的分數」換「整場的手牌」，這就是牌差。

**誘餌**（3 張）是把場上一張非英雄牌收回手牌，兩種用法：

- **回收對手的間諜** → 再打出去，自己再抽 2 張（最常見）
- **回收自己的醫生／關鍵牌** → 同一張效果用兩次

節奏原則很簡單：**第一局用間諜把牌差拉開，第二局用誘餌逼對手跟牌，第三局用剩下的手牌一波帶走。** 北方領域的被動（贏一小局抽一張牌）正好讓這套迴圈滾起來。

![圖 3：誘餌（Decoy）卡面——0 戰力的特殊牌，只能帶 3 張，卻是最影響節奏的一張](https://wsrv.nl/?url=static.wikia.nocookie.net/witcher/images/9/92/Tw3_gwent_card_face_Decoy.png&output=jpg)

## 3. 取得路線（照主線順序買／打）

### 3.1 白果園（離開前務必完成，錯過可能沒了）

- [ ] **誘餌 ×3** — 白果園酒館老闆。**最高優先級**，戰術基石
- [ ] **同袍之情系列、領導號角** — 白果園・哀歌之橋旁商人

### 3.2 威倫（你現在的進度）

- [ ] **領導號角** — 十字路口旅店老闆
- [ ] **迪傑斯特拉** — 任務「昆特：威倫大玩家」，打贏**血腥男爵**
- [ ] **弗農・羅契** — 同上任務，打贏**米德考普斯的哈弟**

### 3.3 諾維格瑞

- [ ] **燒灼** — 鵝陰旅店老闆（*繁中譯名待確認，見 §7*）
- [ ] **伊斯特拉德・蒂森** — 任務「昆特：大城玩家」，於西吉・盧文的浴室打贏迪傑斯特拉
- [ ] **約翰・納塔利斯** — 支線「危險遊戲」，在金鱘酒館向拉比贏取
- [ ] **傑洛特（利維亞的）** — 任務「昆特：老朋友」／「致命陰謀」
- [ ] **希里** — 任務「昆特：大城玩家」

### 3.4 史凱利格

- [ ] **塔勒**（中立間諜）— 大史凱利格西岸・阿林比翁旅店購買
- [ ] **神秘的精靈／阿瓦拉克**（中立英雄間諜）— 大史凱利格東北・蓋迪尼斯，**先完成格瑞米斯特的支線「進階鍊金學」**，再擊敗他取得
- [ ] **葉奈法** — 奧森弗特・鍊金旅店

### 3.5 隨機掉落（無固定點）

- [ ] **菲麗芭・艾哈特** — 與商人、鐵匠、旅店老闆等 NPC 打牌獲勝後隨機取得
- [ ] **金龍（維蘭特雷坦梅斯）** — 同上，純隨機。**中立牌**，任何牌組都能帶

## 5. 對照：普通燒灼 vs 金龍

| 項目     | 燒灼               | 金龍（維蘭特雷坦梅斯）         |
| -------- | ------------------ | ------------------------------ |
| 範圍     | 全場最強單位       | 僅對手**近戰列**最強單位       |
| 觸發條件 | 無                 | 對手近戰列總戰力 ≥ 10          |
| 歸屬     | 中立               | 中立                           |

金龍是**中立牌**，不是北方專屬，任何牌組都能帶；但它只打近戰列，對上怪物、史凱利格這類鋪近戰的牌組特別好用。
