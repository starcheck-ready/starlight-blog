## 0. 30 秒版

- **為什麼現在玩獅鷲**：5.0 技能樹改成前置鏈、每技能 3 級，法印流前期就能成型；獅鷲中甲＋「獅鷲學派技巧」＝法印強度＋體力回復，是同一條線的兩個齒輪。
- **15 等只做三件事**：
  1. 湊齊**基礎獅鷲套**（11 等，威倫尋寶）
  2. 技能點壓在**伊格尼＋亞登**兩條線，補 1 點爆裂護盾保命
  3. **黃褐色貓頭鷹**常駐，體力就是你的彈藥
- **提前開突變五步**：煩惱的詩人 → 來自酒國的使節 → 陶森特 → 大市集 → 面對改變
- **第一個突變**：魔法導體（傷害引擎）；第二個才是刺骨（控場／清雜兵）
- **代價**：15 等打 34+ 的怪，能跑就跑、能輸就輸，進實驗室前先存檔

## 1. 為什麼是獅鷲法印流（5.0 版）

5.0 的四棵技能樹全部重做：**每個技能 3 級、技能之間以前置鏈解鎖**，舊的「系內投入 X 點開下一排」沒了。對法印流的實際意義有三點：

| 5.0 改動                | 對本流派的影響                                                     |
| ----------------------- | ------------------------------------------------------------------ |
| 前置鏈＋每技能 3 級     | 點數更集中：一條法印線走深，比四處撒點有效                         |
| 技能必須放進技能欄才生效 | 欄位有限，**選 6～8 個核心技能**，不是買下整棵樹                   |
| 法印強度重新與等級掛鉤  | 媒體實測伊格尼＋亞登的組合明顯變強；5.01 還給「爆裂護盾」加了傷害反射 |

獅鷲套是**中甲**，每一件都帶法印強度；通用樹的「**獅鷲學派技巧**」則是「每穿一件中甲 → 加法印強度＋體力回復」。這兩件事疊起來，才是法印流能連發的原因：**強度決定痛不痛，體力決定你能不能一直放**。

代價也要講：近戰偏弱、怕圍毆、怕免疫擊倒的怪（石像鬼、古墓女妖）。所以亞登與阿爾德不是配角，是補短板的控場。

> 5.0 讀舊存檔會**退還全部技能點**，任務與裝備保留、構築清空——回流玩家開打前先重配，別拿舊點法去打硬仗。

## 2. 15 等配點（v5.0 三階樹）

### 2.1 預算

- 15 級＝14 點，加上魔力之所（白果園就有 6 處，全遊戲 30 處）首次汲取各 +1 → **實際約 20 點上下**。
- 每技能 3 級，所以「點滿」＝3 點，比舊版便宜，但前置鏈上的路徑也要付費。
- 欄位隨技能點進度解鎖（面板會寫「再獲得 N 點技能點解鎖」），**15 等不可能全開**。

### 2.2 目標配置（約 19 點）

| 法印／系別 | 技能                     | 點數 | 角色                         |
| ---------- | ------------------------ | ---- | ---------------------------- |
| 伊格尼     | 伊格尼強度               | 3    | 主傷害的地基                 |
| 伊格尼     | 熔化護甲                 | 3    | 燒越久護甲越薄，專治重甲人類 |
| 伊格尼     | 火焰之流                 | 1    | 持續噴火，吃體力（見 §4）    |
| 亞登       | 亞登強度                 | 3    | 圈內減速＋強化後續傷害       |
| 亞登       | 強化符文                 | 3    | 站在圈裡每秒掉血             |
| 亞登       | 魔法陷阱                 | 1    | 範圍更大，適合風箏           |
| 昆恩       | 爆裂護盾                 | 1    | 破盾擊退，保命用             |
| 通用       | 獅鷲學派技巧             | 3    | 每件中甲：法印強度＋體力回復 |
| 通用       | 生存本能                 | 1    | 血量% 提升，前期容錯         |

**合計 19 點**，剩 1～2 點留給後面的「催化劑」。

### 2.3 購買順序（重要）

1. **先墊 1 級解鎖前置**：前置鏈需要先買的節點，各給 1 點就好，別一次點滿。
2. 回頭把**伊格尼強度、亞登強度、獅鷲學派技巧**補到 3。
3. 再補**熔化護甲、強化符文**到 3。
4. 最後才碰替換模式（火焰之流、魔法陷阱）與跨法印技能。

> 為什麼不點阿爾德？15 等點數不夠。阿爾德橫掃很好用，但那是 20 等之後的第二步；現階段用亞登圈地＋伊格尼輸出更穩。

### 2.4 跨法印技能：催化劑（後補）

「**催化劑**」讓被亞登標記的敵人，之後吃阿爾德與伊格尼更痛——這正是本流派「先圈再燒」的官方背書。15 等點數不夠，等 20 等再補；若你常打群怪，它的優先度可以排在高級替換模式之前。

### 2.5 突變誘發物

藍色誘發物放藍色技能旁邊（法印強度），紅色配戰鬥、綠色配煉金。5.0 沒有重新公布相鄰協同的具體數值，**依面板提示擺同色**即可，不要照舊攻略的固定百分比算。

## 3. 裝備：11 等就能穿的獅鷲套

| 階段   | 等級（約） | 取得                                                           |
| ------ | ---------- | -------------------------------------------------------------- |
| 基礎   | 11         | 威倫尋寶任務「獅鷲學派裝備」，6 張藍圖（4 甲＋鋼劍＋銀劍）     |
| 強化   | 15～18     | 用基礎套當材料升級（各攻略口徑不一，以圖紙為準）               |
| 優越   | 26         | 同上                                                           |
| 大師   | 34         | 同上                                                           |
| 宗師   | 40         | 血與酒，向陶森特師匠接宗師尋寶                                 |

要點：

- **不要賣掉舊階裝備**。獅鷲套是階梯式升級，下一階要吃上一階的成品。
- 基礎套在威倫就能做完，15 等正好穿；四件套的法印強度加成，是你傷害的第一根支柱。
- **5.0 的 Reforge 只改外觀、不動數值**（諾維格瑞的哈托利、烏鴉窩的尤娜）。所以「最強」與「最好看」不再二選一：穿數值最好的，外觀去鐵匠鋪解決。
- 符文石優先插**法印強度**，其次伊格尼／亞登專屬；有多少插多少，不用等完美。
- 劍也重要：後面的「魔法導體」是吃**劍傷**的，獅鷲雙劍或任何高傷銀劍都算投資。

## 4. 藥水：黃褐色貓頭鷹（15 等唯一指定）

> 繁中版把 Stamina 譯作「體力」；舊攻略若寫「耐力」「精力」，指的都是同一條資源。

| 版本     | 效果（經典數據）                                 |
| -------- | ------------------------------------------------ |
| 基本     | 加速體力回復，30 秒                              |
| 強化     | 加速體力回復，時間更長                           |
| 高級     | 加速體力回復，**夜晚期間不會結束**               |

為什麼是它：

- 火焰之流是**持續消耗體力**的施放模式，亞登、昆恩、阿爾德也都要體力。法印流的 DPS 本質上是「體力換傷害」。
- 貓頭鷹＝把體力回復拉快，等於把整套迴圈的節奏拉快；毒性只有 20，跟燕子併用不會爆毒。
- 15 等通常已有強化版；高級版圖紙要白色海鷗酒，前期不一定湊得齊，**有強化版就先喝**。

搭配建議：貓頭鷹（常駐）＋燕子（回血）；雷霆之類的攻擊藥水對法印流收益低，別浪費毒性。後期再上煎藥（海克娜這類「消耗體力就回血」的煎藥跟本流派很合）。

## 5. 15 等提前開突變：五步流程

### 5.0 前置觀念

- 「面對改變」是血與酒的**支線**，但要先讓它出現：**完成諾維格瑞主線「煩惱的詩人」（救出丹德里恩）**，血與酒的入場任務「來自酒國的使節」才會出現在告示板上。
- 另一個選項是主選單直接「只玩血與酒」，系統會給你 34 等傑洛特——那是**另一個存檔**，跟本流程（本體 15 等偷跑）不同，突變要重解。
- 全程心態：目標只有「拿到蛋白、解鎖突變」。怪能繞就繞、任務能輸就輸。

### Step 1：煩惱的詩人（諾維格瑞主線）

### 5.5 15 等偷跑守則

1. **先存檔**：接使節前、進陶森特前、進實驗室前、進機器前，各存一個。
2. **難度可以調**：偷跑不是榮譽挑戰。真的過不去，暫時切「只看劇情」，甚至開 5.0 新增的無障礙預設「吟遊詩人謠曲」（生命回復、無限耐久等），拿完突變再調回。
3. **只打必打的**：實驗室怪物不清場也能拿蛋白；石像鬼、古墓女妖免疫擊倒，別跟她們耗。
4. **體力就是命**：貓頭鷹常駐，昆恩破了先退，不要站著施法。

## 6. 第一個突變：魔法導體（替代：刺骨）

| 突變         | 效果（社群／經典版描述）                                             | 成本（依面板）                       | 適合                     |
| ------------ | -------------------------------------------------------------------- | ------------------------------------ | ------------------------ |
| **魔法導體** | 法印額外造成傷害，量級與**劍傷**掛鉤（約 50%）；4.0 起大幅加強       | 2 點技能點＋大型突變誘發物（多為藍色） | 主傷害，伊格尼／亞登最受惠 |
| **刺骨**     | 阿爾德有機率**凍結**，凍結目標被擊中即碎裂（即死）                   | 2 點技能點＋大型突變誘發物（顏色依面板） | 清雜兵、群控             |

- **15 等先點魔法導體**。它把你的「劍」也變成法印的一部分：劍越好，火越痛。這也是為什麼 §3 說劍不能省。
- 刺骨很爽，但它的價值在「凍住→即死」，對後期打不出擊倒／免疫控制的精英會打折；點數有餘再研究。
- 大型誘發物不夠時：實驗室與洞窟內有幾個現成的可撿；也可以把 3 個同色小誘發物合成大型。
- 突變面板裡另有解鎖**額外技能欄**的節點，那是 20 等之後的事，15 等別碰。
- 面板入口：PC 按 **C** → 突變；初始一次只能裝備一個突變。

## 7. 實戰循環

**開場**：昆恩 → 亞登（魔法陷阱）→ 伊格尼（火焰之流）→ 阿爾德橫掃 → 追擊倒地目標

| 情境         | 打法                                                                 |
| ------------ | -------------------------------------------------------------------- |
| 群怪         | 亞登圈住一群 → 火焰之流掃一排 → 阿爾德橫掃擊倒 → 補刀；體力見底就退   |
| 單體／人形    | 亞登減速 → 伊格尼熔甲 → 保持 5 步距離，別進劍圍                       |
| 高你 10 級以上 | 只做任務目標：亞登風箏、繞柱、跑酷；不要為了經驗硬打                  |
| 免疫擊倒      | 石像鬼、古墓女妖：改成「亞登＋伊格尼」磨，或直接無視                  |
